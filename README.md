# SkinCancerDetection
Dataset Source:
https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000
**Tech Stack:** Python, TensorFlow, Keras, CNN, HAM10000 Dataset, Streamlit, NumPy, Pandas, Matplotlib, Seaborn, Plotly, Scikit-learn

**Project Description**

Developed a deep learning-based medical image classification system for automated skin cancer detection using the HAM10000 dataset. The project focused on classifying dermatoscopic images into seven different skin lesion categories using Convolutional Neural Networks (CNNs). The workflow involved image preprocessing, augmentation, model training, and evaluation to improve classification accuracy and generalization. Various augmentation techniques were applied to address dataset imbalance and enhance model robustness. The trained model was integrated into an interactive Streamlit application for real-time image upload and prediction. Performance evaluation was conducted using confusion matrices, classification metrics, and visualization-driven analysis.
